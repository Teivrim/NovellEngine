# NovellEngine

Редактор визуальных новел на C++20 / Win32. Таймлайн, панель скрипта,
иерархия сцен, инспектор, браузер ассетов, undo/redo, свой формат
проекта `.vne`.

**3 319 строк, ноль сторонних библиотек.** Только системные Win32, GDI
и GDI+. Ни VCL, ни Qt, ни DirectX — только то, что уже есть в системе.

## Зачем редактор, когда есть Ren'Py

Ren'Py и VN.py — скриптовые. Там пишут текст с разметкой, а сцены и
переходы описывают кодом. Здесь редактор с таймлайном и инспектором:
визуальная новелла собирается мышью, как в видеоредакторе, а на выходе
получается обычный скрипт, который читает любой рантайм.

## Как устроено

```
include/
  EditorPanels.hpp     описание панелей интерфейса
  GraphicsAPI.hpp      абстракция рендера
  ProjectManager.hpp   чтение/запись .vne
src/
  main.cpp             252 стр. — точка входа и цикл приложения
  UI/EditorPanels.cpp   2 289 стр. — панели, таймлайн, инспектор
  Graphics/WinAPIGraphics.cpp   458 стр. — рендер на GDI+
  Core/ProjectManager.cpp        77 стр. — формат проекта
```

Рендер вынесен за `GraphicsAPI.hpp`, хотя реализация одна. Это сделано
для того, чтобы позже можно было подключить Direct2D или OpenGL, не
трогая панели: панели знают только про интерфейс и ничего не знают
про то, как рисуется фон.

Undo/redo сделано на уровне команд, а не на уровне снимков состояния:
панели отправляют команду, `UndoManager` держит стек. Снимок всей сцены
на каждое действие при таком размере проекта — это несколько мегабайт
на щелчок мыши.

## Сборка

```bash
build.bat            # MinGW g++, -std=c++20, -static
package.bat          # сборка + упаковка в dist/
```

Один `build.bat`, без CMake: у проекта нет внешних зависимостей, и
генерировать сборочную систему ради одной команды было бы лишним.

## Границы

- Рендер — GDI+. Он программный, поэтому интерфейс не аппаратный.
  Для редактора интерфейса это не критично, для видео было бы.
- Экспорт скрипта поддерживает свой формат `.vne`; конвертация в формат
  конкретного рантайма (VN.py, Ren'Py) не реализована.
- Windows-only. Сборка на MinGW, проверялась на Windows 11.
